🏦 Simulador Bancário em Java

Um sistema de terminal desenvolvido em Java para simular operações financeiras básicas de uma conta corrente. Este projeto foi criado para consolidar fundamentos de programação e aplicar regras de negócio do setor financeiro.

🚀 Funcionalidades

O sistema apresenta um menu interativo com as seguintes operações:
- *Consulta de Saldo:* Exibe o saldo atualizado do cliente.
- *Recebimento de Valores:* Adiciona um valor de depósito ao saldo atual.
- *Transferência de Valores:* Permite simular um pagamento/transferência, incluindo *validação de regra de negócio* (impede a transação se o saldo for insuficiente).
- *Tratamento de Exceções Simples:* Identifica e alerta o usuário caso uma opção inválida seja digitada no menu.

💻 Tecnologias e Conceitos Aplicados

- *Text Blocks*: Uso de (""") para formatação limpa de strings e menus.
- *Estruturas de Repetição:* Uso de while para manter o sistema rodando.
- *Estruturas de Decisão:* switch-case para o controle do menu e if-else para as validações financeiras.
- *Entrada de Dados:* Classe Scanner para interação via console.
